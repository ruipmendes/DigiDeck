Six changes that don't fit under one banner: icon packs get in-app upload + tint modes, Nanoleaf goes real-time, Streamlabs closes most of the OBS parity gap, Twitch/Kick reach single-message-delete parity, Hue gets a stronger LAN posture, and a broader hardening pass touches HTTP, WebSocket, URL handling, and archive extraction.

## Icon packs: zip upload + per-pack tint mode

Two follow-ups to the v0.4-era icon-packs feature.

- **`+ zip` button in the icon picker.** Drop a `.zip` on the picker (default name pulled from the filename, editable), and Digi Deck extracts the SVGs into a new pack folder. Auto-strips a common container prefix so GitHub-style archives (`repo-branch/…`) land clean at the pack root. 50 MB upload cap; individual SVGs capped at 512 KB. Path-traversal guards on every entry.
- **Per-pack tint** toggle. Each pack section in the picker gets an `invert / native` two-choice control. `invert` (the historical default) matches Simple Icons' monochrome-black convention; `native` skips the CSS filter so packs that already ship colored SVGs render as drawn. Settings persist to a `%APPDATA%/digi-deck/icon-pack-settings.json` sidecar outside the packs folder so users can sync `icon-packs/` externally.

## Nanoleaf: real-time via SSE

The Nanoleaf integration used to poll `/state` + `/effects` every 5 s. It now subscribes to Nanoleaf's server-sent-events stream at `/api/v1/<token>/events?id=1,3` (state + effects namespaces). Flips from the Nanoleaf app, a physical remote, or a rhythm module land in tiles instantly instead of on a poll boundary. Bounded exponential-backoff reconnect (2 s → 60 s) on drops.

## Streamlabs: closer to OBS parity

Everything Streamlabs Desktop's JSON-RPC surface actually exposes:

- **New op** `refresh-browser-source` — pick a browser source from a live picker, and Digi Deck fires `SourcesService.getSource(id).refresh()` on tap. Great for chat overlays, alertboxes, and any web widget that got stuck.
- **Live label variables**: `{streamlabs.recordingTime}`, `{streamlabs.streamingTime}`, `{streamlabs.droppedFrames}`, `{streamlabs.currentScene}`, `{streamlabs.cpu}`, `{streamlabs.fps}`, `{streamlabs.bandwidth}` (auto-formatted kbps/Mbps). Timers tick locally between broadcasts using ISO `*StatusTime` fields from `StreamingService.getModel()`.
- **Chart sources**: `streamlabs.droppedFrames`, `streamlabs.cpu`, `streamlabs.fps` — pairs nicely with the value-based [color thresholds](https://github.com/ruipmendes/DigiDeck/releases/tag/v0.9.0) shipped in v0.9.
- Data comes from a 2 s `PerformanceService.getModel()` poll started/stopped alongside the existing audio poll.

Media source play/pause and scene screenshots aren't implemented — Streamlabs Desktop's public API doesn't expose them, and the undocumented `HotkeysService` fallback isn't a stable base to build on.

## Twitch: single-message delete

Kick has had `delete-message` for a while; Twitch only had bulk `clear-chat`. Adds `delete-message` via `DELETE /moderation/chat/messages` (uses the existing `moderator:manage:chat_messages` scope — no re-consent). The messageId field supports prompt-at-tap, so you can bind a tile to "delete a message" and paste the id from a chat client on demand.

## Hue: TOFU cert pinning

The Hue integration now pins the bridge's TLS cert fingerprint on first link and verifies every subsequent request against it before any application data goes out on the socket. Bridge swaps and firmware-triggered cert rotations are handled by clicking Disconnect + Link again.

## Hardening

Various tightenings across HTTP, WebSocket, URL handling, and archive extraction paths. Nothing user-visible.
