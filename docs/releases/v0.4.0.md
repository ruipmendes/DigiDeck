Kick lands as a first-class integration, and chart tiles show up as a whole new tile kind.

## Kick integration (new)

Two-tier rollout of Kick — Twitch's biggest competitor.

**Tier 1 — mod & broadcast ops:**
- Chat (with prompt-at-tap or static text).
- Moderation: delete message, ban user, unban user (with duration + reason).
- Broadcast: update title, update category, run ad.

**Tier 2 — live-status + labels:**
- **Kick streamer tiles**: paste a slug + optional avatar URL (Kick's OAuth API doesn't expose other users' pics — right-click the profile picture on kick.com → *Copy image address*). Tile renders the avatar with a live/offline dot.
- Dynamic labels: `{kick.channel}`, `{kick.live}`, `{kick.viewers}`.
- Chart source: `kick.viewerCount` — sparkline of viewer count while you're live.

## Chart tile kind (new)

- New `chart` tile type. Renders a rolling sparkline of a numeric integration variable (~90 s window, 1 Hz sample rate).
- Sources this release ships:
  - `obs.droppedFrames` (delta mode — the counter's monotonic, delta shows *when* drops happen)
  - `spotify.volumePercent`
  - `kick.viewerCount`
  - `system.cpu`, `system.ram`, `system.gpu`
- System metrics sampler powered by PowerShell perf counters. Only runs when at least one chart tile in the current layout references a `system.*` source.
- Value or delta mode. Auto-scale, or fix y-axis via `min` / `max`.

## Version chip in tray

Tray now shows the running version at boot — helps catch "tray reads the version at startup" mismatches when you upgrade in place without restarting.

## Templates refresh

Starter templates updated for v0.3.0 additions (Spotify + per-app audio + OBS depth).
