First numbered release. Everything in main as of this tag is the baseline going forward.

## What's in it

**Core deck**
- Phone PWA + Windows server over LAN WebSocket, QR-code pairing with token auth, mDNS service advertisement
- Multi-page layouts with **tabs** or **folders (back-stack)** navigation
- Per-page column count (1-4), per-button image upload (PNG / JPG / **GIF** / WebP, Stream Deck-style full-bleed fill)
- Multi-action **sequences**, **wait** / delay step between actions
- **Long-press** secondary action with phone-side hold detection (~500ms threshold + stronger haptic)
- Haptic + scale-on-press feedback
- Localhost grid preview from the PC (no token needed)

**Integrations**
- **OBS Studio 28+** via `obs-websocket` v5 — record / stream / virtual cam / replay buffer / scene switching / source visibility / mute / audio mixer slider tiles
- **Streamlabs Desktop** via JSON-RPC over SockJS — full button-action parity with OBS (except audio mixer sliders, [tracked here](../../issues/1))
- **Twitch** — chat-from-button + streamer thumbnail tiles with live/offline state
- **System mic** mute via Windows Core Audio
- **Hotkey** recording UI (no need to type key names)

**Layout management**
- Starter **templates** (Stream Focused, Chat Commands, System Controls) with live preview before apply
- **Export / Import** layouts as self-contained `.json` bundles (embedded images, content-hashed)
- Per-tile and per-page image uploads

**Operations**
- One-shot **install.bat** (Node via winget if missing, npm install both sides, desktop shortcut)
- System tray icon with reload / restart-integrations / **check for updates** / quit
- Auto-reconnect for OBS + Streamlabs (5s interval, 5 min budget, manual retry afterwards)

## Known gaps (tracked as issues)
