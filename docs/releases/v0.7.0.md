One new integration, a new tile-agnostic action type, a UI made for scale, and a power-user touch on Home Assistant.

## Mix It Up integration (new)

Mix It Up is the widely-used Windows streamer bot with a chat-command graph, timers, currency, counters, event hooks, and overlays. Rather than reimplementing any of that, Digi Deck now integrates with it — turning the phone into a physical control surface for whatever elaborate command chains you've already built inside MIU.

- **REST v2 Developer API** on `http://localhost:8911` — enable it once in *Mix It Up → Services → Developer API → Connect*.
- Ops: **run-command** (with args + `IgnoreRequirements` bypass), **enable / disable / toggle command** (tile lights when the target command is currently enabled), **chat-message** (cross-platform via MIU's own routing — Twitch / YouTube / Trovo / Kick), **chat-clear**, **counter set / update / reset**.
- Command dropdown: enabled first, then by group, then by name — stays scannable for MIU setups with hundreds of commands.
- Version + command + counter catalog polled every 10-30 s (cheap heartbeat, less-frequent full refresh).

## Soundboard (new action type)

- New `sound` action — any button can play a local audio file (MP3, WAV, WMA, AAC, FLAC — anything Windows Media Foundation supports).
- **Per-clip volume** (0-100%) so you can pre-balance loud clips against quiet ones.
- **Server-side playback** — audio comes out of the PC's default output so it lands in OBS (route via VoiceMeeter / VB-Cable) rather than through the phone speaker.
- Powered by WPF's `MediaPlayer` on an STA-mode PowerShell host with a proper `Dispatcher.Run()` pump — routes through WASAPI, the same low-latency stack Groove Music and Spotify Desktop use. Buttery-smooth playback with none of MCI's stuttering.
- Absolute file paths (matches the `launch` action's pattern) — no upload dir, point at your existing sound folder.

## Integrations panel — sidebar + detail pane

- **New layout**: left rail lists every integration by category (Streaming / Lighting) with icon + name + status dot; right pane shows the selected integration's config panel.
- Only **one panel visible at a time**, so vertical scroll cost stays constant as we add more integrations.
- **Auto-select on open**: first *connected* integration wins, falling back to first *enabled*, falling back to first in list.
- **Narrow layout (≤ 700 px)**: rail collapses into a horizontal scrollable chip strip above the detail pane via `matchMedia`.
- **Brand accent colors** on the rail icons — Twitch purple, Kick green, Spotify green, etc. — tinted when connected, gray when idle.
- The old collapse-to-pills-row summary is now a single-line status counter: *"3 connected · 5 enabled · 11 available"*.

## Home Assistant entity-search typeahead

Replaces the earlier "text filter + dropdown" pair, which became unusable once an HA setup crossed ~50 entities.

- **Search input backed by an inline result list**. Keyboard nav (↑↓ Enter Esc), highlighted row scrolls into view, click or Enter picks it.
- **Matches on both friendly name AND `entity_id`** — search "living" for a friendly-name match, or "light." to filter by domain prefix.
- Result list capped at 50 with a *"Showing first 50 of N"* footer when there are more — protects the DOM on wide HA setups.
- **Clear button** (×) inline when a value is picked.
- Falls back to a plain text input when zero entities are loaded (HA offline, deck author typing an entity manually).
