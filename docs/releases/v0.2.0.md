Big release — 48 commits since v0.1.0. Two new integrations reach maturity, HTTPS ships opt-in, and the phone picks up prompt-at-tap for actions that need late-binding input.

## Discord integration (new)

Full control of your local Discord client via its RPC pipe.

- **Voice control**: mute / deafen / push-to-talk mode toggles, plus noise-suppression (Krisp), automatic gain control, echo cancellation.
- **Voice channels**: join a specific channel, leave, or ask on tap and pick from a dropdown of every voice channel across your servers.
- **Per-member ops**: set someone's volume for you specifically (0-200%), server-side mute/unmute a member for yourself.
- **Move members**: pull someone from another VC into yours, or move them to any channel — with a picker of everyone voice-connected in your server.
- **Voice sliders**: microphone volume (tap to mute), voice output volume (0-200% to match Discord's native boost, tap to deafen), voice-activity sensitivity threshold.
- **Live state**: every tile lights up to match Discord (muted / deafened / PTT-on / current channel / filter state) and sliders track Discord's own volume in real time.
- **Server icons as tile thumbnails**: join-channel tiles auto-render the target guild's icon.
- **Primary server setting**: pick your home Discord in the panel; channel/member pickers default to just that server.

## Twitch Quick Actions (Tier 1, 2, 3)

- **Mid-stream ops**: chat announcements, clear chat, create clip, stream markers, run ad / snooze ad, toggle Shield Mode, chat modes (emote-only, sub-only, follower-only, slow).
- **Broadcast ops**: raid / cancel raid, shoutout, update stream title, change category.
- **Polls & predictions**: title, choices/outcomes list, duration — one press fires the whole thing.
- **Prompt-at-tap for raids and shoutouts**: leave the target field blank in config, pick it on the phone at press-time.

## Prompt-at-tap mechanism

Any action can declare `prompts` — the phone shows a modal to collect values before firing. Sources support dropdown pickers (Discord channels, Discord members, custom text). Config-time editor also renders pickers instead of raw ID paste when data is available.

## HTTPS / WSS (opt-in)

Per-install security setting to serve the server over TLS. Self-signed cert auto-generated, one-click Windows trust install. Adds an HTTPS variant of every OAuth callback URL.

## Templates panel

Curated starter layouts (Stream Focused, Chat Commands, System Controls). Preview them full-screen before applying.

## Brand icons in the icon library

Discord, Twitch, Kick, OBS, Streamlabs SVG marks available in the icon picker.

## Update flow polish

- Balloon-tip notification the moment you click "Check for updates" — no more silent 1-3 second gap.
- Result dialog surfaces reliably on top of full-screen games / browsers.
- Apply-update PowerShell window stays open with a "Press Enter to close" — plus a yellow note reminding you to pull-to-refresh the phone browser if the UI still looks old.

## Reconnect required on upgrade

Twitch and Discord both added OAuth scopes across this release. On first "insufficient permission" error, open the integration panel → *Disconnect* → *Connect* — one round-trip re-approves with the full scope set.
