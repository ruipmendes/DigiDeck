A new game category kicks off with Elite Dangerous, chart tiles gain color bands, and Stream Deck profiles import in one click.

## Stream Deck profile import (new)

**Move your Stream Deck profile to your phone in one click.** Export your profile from the Stream Deck app (`File → Export`), drop the `.streamDeckProfile` file onto Digi Deck via **Header menu → Import Stream Deck profile…**, and you get a preview banner with the imported layout.

Handled action types: system (website / open / hotkey / text / delay), multi-actions (→ sequences), profile rotate (→ goto-page across generated pages), OBS (scene / recording / streaming / mute / replay buffer), Discord (mute / deafen / PTT), Spotify (play-pause / next / previous), Streamlabs (recording / streaming / scene). Anything third-party lands as a text tile with the original title so you can see what got dropped, and the preview alert lists the unmapped set.

Not yet tested against a real `.streamDeckProfile` (dev doesn't own a Stream Deck) — ships on defensive parsing. If your hotkey bindings come through garbled, that's the first thing to file.

## Elite Dangerous integration (new)

First game integration and the seed of a new **Gaming** category in the Integrations sidebar. Read-only over the Frontier-shipped Journal API — no output ops (Elite has no RPC surface); you control the game via existing hotkey tiles.

**What it surfaces:**
- **Live ship state** from `Status.json` — fuel, cargo, and the 32-bit `Flags` bitmask decoded into readable flags (docked / landed / supercruise / hardpoints / cargo scoop / gear / silent running / FSD charging & cooldown / low fuel / overheating / night vision / etc.).
- **Session state** by tailing the current `Journal.*.log` — commander, ship type + custom name, current system + station, credits, active missions. State backfills on start so tiles render right when Digi Deck launches mid-session.
- **Credits stay live** off a LoadGame baseline + accumulated per-event deltas (bounties, market buy/sell, exploration data, vouchers, refuel / repair / ammo, drones, module & shipyard buy/sell with trade-in, mission rewards, community-goal rewards).
- **Missions** tracked across accept / complete / fail / abandon / redirect events with the periodic Missions snapshot merged in, so entries from prior sessions show up too. Panel lists up to 8 active missions with per-row expiry countdowns.

**Label variables**: `{elite.commander}`, `{elite.system}`, `{elite.station}`, `{elite.ship}`, `{elite.shipName}`, `{elite.credits}` (formatted B/M/k Cr), `{elite.fuelPercent}`, `{elite.cargoTons}`, `{elite.status}`, `{elite.missionCount}`, `{elite.missionReward}`, `{elite.nextExpiry}`.

**Chart sources**: `elite.fuelPercent`, `elite.cargoTons`, `elite.credits`, `elite.missionCount`, `elite.missionReward`.

**Tile presets**: system / ship / credits / status labels, fuel & cargo sparklines, mission count / pending reward / next-expiry countdown labels, mission count & reward charts.

## Chart color thresholds (new)

Chart tiles gain an optional **thresholds** field — paint the sparkline stroke and current-value text a specific color when the latest sample falls **at or below** or **at or above** a threshold value. Layered: the last matching band in the list wins, so you can stack `at or below 25 → amber` and `at or below 10 → red` for a fuel-warning shape. Or `at or above 80 → amber`, `at or above 95 → red` for a CPU-danger shape.

Edit thresholds inline in the chart tile editor — add / remove rows, switch each between at-or-below and at-or-above, pick a color. The Elite fuel chart preset ships with the 25 / 10 fuel warning bands baked in to match Elite's own in-game convention.

## Fixes

- **HotkeyInput: Escape is now bindable.** Previously Escape was hard-coded as "cancel recording" and missing from the key map, so it could never be recorded. Cancel now comes from a dedicated ✕ button while recording and from clicking anywhere outside the input; Escape records like any other key.
