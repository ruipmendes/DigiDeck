Fourth lighting integration lands, the enable/disable UX gets normalized across every panel, and a security review pass ships one real fix.

## Nanoleaf integration (new)

- **Button-press pairing** — hold the controller's power button 5-7 s until the LED flashes, click *Link* in Digi Deck within 30 s.
- Ops: `power-{on,off,toggle}`, `effect-select`, `identify` (brief pulse for verifying you've got the right controller).
- Brightness slider (tap to toggle, drag to dim).
- Live state: current effect + brightness + panel count + firmware version visible in the panel; effect tiles light up when their effect is the currently-selected one.
- Effect dropdown in the editor populates from your Nanoleaf app's saved effects.

## UX consistency

- **OBS and Streamlabs panels** now use the same enable/disable pattern as every other integration (previously they had an inline checkbox at the top instead of the standard "Enable button when disabled, underline link when enabled" flow).
- **"Disable integration" link now shows during setup** — previously if you enabled an integration and then bailed without finishing the config, you were stranded because the disable link was hidden behind a `state !== 'not-configured'` guard.

## Security

- **JSON request body cap**: 50 MB, matching the image upload path. Protects against memory exhaustion via oversized POSTs. Result of a targeted security review pass that also verified: publicConfig hides secrets across all integrations, PowerShell escaping is safe, path traversal is blocked on image / icon-pack routes, SVG CSP is tight, Origin + Host + CSRF checks pass on every mutating route, tokens compared with timing-safe equality, no secrets in log output.

## Templates

Three v0.5-era templates added (Streamer + Ambient, Gamer, Focus) — pre-built decks that showcase the multi-integration lighting story.
