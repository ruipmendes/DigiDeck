Digi Deck grows up a bit: the server now runs on **macOS and Linux**, HTTPS works everywhere, CI tests all three OSes on every change, and the tray gets the brand mark + a submenu once the integration list fills up.

## Server: cross-platform (macOS + Linux)

Windows is still the first-class target — tray icon, native file dialog, Core-Audio mic / per-app audio, Voicemeeter, one-click HTTPS cert trust. But the server now boots on macOS and Linux too, delivers the whole deck experience, and degrades the Windows-only extras with friendly errors instead of crashing.

**Works everywhere:**
- The deck UI, pairing, QR, mDNS discovery
- Every integration — OBS, Streamlabs Desktop, Twitch, Kick, Discord, Spotify, Hue, Home Assistant, OpenRGB, Nanoleaf, Mix It Up, Voicemod, Elite Dangerous
- Hotkey / text / launch / url / script / sound actions (sound uses `afplay` on macOS, `paplay` on Linux)
- HTTPS — pure-JS cert generation via the `selfsigned` npm package, no OpenSSL
- CPU + RAM chart sources
- Config URL opening in the default browser (`rundll32` / `open` / `xdg-open`)

**Windows-only, degrades cleanly elsewhere:** tray icon, native file-browse dialog, mic mute, per-app audio, Voicemeeter, GPU chart source, one-click cert-trust install.

Launch with `./start.sh` on macOS / Linux (next to `start.ps1` on Windows). See [INSTALL.md](https://github.com/ruipmendes/DigiDeck/blob/v0.11.0/INSTALL.md) for the macOS + Linux section — git clone + `npm ci` + `./start.sh`.

Per-user data lives in the OS-appropriate location: `%APPDATA%` on Windows, `~/Library/Application Support` on macOS, `$XDG_CONFIG_HOME` / `~/.config` on Linux.

## Tray: brand icon + "Restart integration" submenu

The tray drops the generic Windows icon in favour of the same 2×2 grid mark the client PWA uses — drawn at runtime with `System.Drawing`, no binary asset shipped.

When more than four integrations are enabled, the flat "Restart X connection" items collapse under a single **Restart integration ▶** parent so the right-click menu stays scannable as the integration list grows. Order: version → open config → reload layout → restart integration ▶ → check for updates → quit.

## CI matrix

New workflow at [.github/workflows/ci.yml](https://github.com/ruipmendes/DigiDeck/blob/v0.11.0/.github/workflows/ci.yml) typechecks + builds server and client on `windows-latest`, `macos-latest`, and `ubuntu-latest` for every push to main and every PR. Catches cross-platform regressions before they land.
