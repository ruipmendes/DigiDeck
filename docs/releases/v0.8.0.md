Two new integrations round out a fresh Mixers category, and the v0.7 soundboard grows a proper library UI.

## Voicemod integration (new)

Real-time voice changer + soundboard for streamers, via the documented Control API WebSocket. Voicemod is massive on Twitch (voice-changer tags, meme clips, VTuber transformations); Elgato's Stream Deck already has a first-party plugin — this makes Digi Deck the first PWA-based deck with it.

- **Setup**: request a client key from Voicemod's Control API dev portal (free, single form), paste it into the Voicemod panel. Digi Deck attaches over `ws://localhost:59129/v1/`.
- Ops: **voice-changer-toggle** (tile lights when on), **select-voice** (pick from your live voice list — favorites and custom voices surface first), **mic-mute-toggle** (Voicemod-owned mic mute, distinct from Windows-level), **play-sound** (pick from your soundboard — 800+ clips populate live from the app).
- Live state from `voiceChangerEnabledEvent`, `voiceChangedEvent`, `toggleMuteMic` push events — tiles reflect what's happening in Voicemod's own UI, whether you flipped it there, from Digi Deck, or from another remote.

## Voicemeeter integration (new)

Windows audio mixer control — the Wave Link alternative every streamer already recommends when Elgato's own tool doesn't work out. VBVMR_* C API via native FFI to `VoicemeeterRemote64.dll` (auto-detected at standard install paths).

- Detects edition (Standard / Banana / Potato) on connect and shapes strip / bus / route enumeration accordingly.
- Ops: **strip mute / solo / route toggle** (per bus — A1/A2/A3 physical outs, B1/B2/B3 virtual outs), **bus mute toggle**, **restart audio engine**.
- Slider provider `voicemeeter` — `inputName` encodes `strip:<idx>` or `bus:<idx>`; drag drives Gain (-60..+12 dB linear), tap toggles mute.
- Real-time state via `IsParametersDirty()` at 10 Hz; optimistic local updates on our own writes so the UI doesn't wait a poll tick.
- **The Wave Link workflow**: separate stream and monitor mixes from the same input source, controlled from a phone tile.

Curated tile presets: cough button (mute mic on B1 stream only), strip mute, strip gain slider, bus gain slider.

## Sound library UI (soundboard follow-up)

The v0.7 soundboard action grows the Sounds panel it was missing.

- **Drop audio files** into `%APPDATA%/digi-deck/sounds/` (same folder-discovery pattern as icon-packs). Sub-folders become groups. MP3, WAV, WMA, AAC, FLAC — anything Windows Media Foundation supports.
- **Preview each clip** in the panel through the config UI's own `<audio>` element — audible only through your headphones, so you can audit without accidentally airing an airhorn on stream.
- **Test on stream output** button runs the clip through the deck's audio path — for OBS virtual-cable routing checks.
- **Per-clip default volume** persists to `sounds.json` and auto-applies when you next add the clip to a tile — set your airhorn to 40 % once and every new tile inherits it.
- **Editor library-mode dropdown** — sound tiles now default to picking from the library (id-based reference, portable across machines via bundle export/import); the old absolute-path mode still works for external files.

## Integrations panel: Mixers category

Sidebar gains a third category alongside Streaming and Lighting: **Mixers** — home to Voicemeeter and Voicemod. Rail auto-selects the first *connected* integration on open, so the config UI opens on something useful instead of an empty state.
