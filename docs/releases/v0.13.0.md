Three cross-platform follow-ups from the v0.11 port, plus a security hardening pass that followed last cycle's targeted re-audit.

## macOS mic mute

The Mic action previously failed closed on macOS with a "Windows-only" message. It now works natively via `osascript`:

- **Mute** sets the system input volume to 0.
- **Unmute** restores the last non-zero level the controller observed — so toggling off and back on gets you the actual level you had set, not a hardcoded default. First toggle (before any observation) falls back to 75.
- Polling runs on macOS too, so tiles reflect state changes you make from the menu bar / shortcut keys / other apps.

Linux still unsupported (pactl / wpctl vary by distro + session manager); fails closed with the same friendly error as before. Workaround: a hotkey tile bound to your DE's mute shortcut, or `pactl set-source-mute @DEFAULT_SOURCE@ toggle` via a script action.

## Linux sound: aplay fallback

The Sound action's Linux path tries `paplay` (PulseAudio / PipeWire-pulse) first, then falls back to `aplay` (ALSA) on distros that don't ship pulse. The caveat: `aplay` has no volume control, so the clip plays at system volume and a message logs explaining why.

Covers the "minimal distro / headless Linux" case where paplay isn't installed and sound would otherwise silently fail.

## Tray: explicit "no tray by design" note

The tray was already Windows-only but silent about it on other OSes. The server now prints a one-line banner at boot on macOS / Linux pointing at Ctrl+C in the terminal + the config page URL as the equivalents. INSTALL.md gained matching per-OS sections for sound playback and mic mute behavior.

Why no cross-platform tray? The viable npm option (`systray2`) hasn't been updated since 2022 and ships a ~5 MB Go binary per platform. Users already running `./start.sh` from a terminal have Ctrl+C and a browser tab on the config page covering the same workflow; the cost/benefit on an untested dep didn't earn it.

## Security hardening

Post-sweep fixes bundled under a discreet commit as usual:

- Inbound streaming sources cap buffer growth between frame boundaries so a compromised LAN device can't OOM the server with unbounded data.
- URLs received from upstream migration messages are validated against the expected hostname before honoring them.
- Outbound relay targets are allow-listed to known push providers; opaque third-party endpoints are rejected at subscription time.
