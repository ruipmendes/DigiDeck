Two new integrations, OBS goes deeper, and the action picker becomes search-first. 17 commits since v0.2.0.

## Spotify integration (new)

- OAuth playback control: play / pause / next / previous, volume via slider tile.
- **Now-playing labels**: use `{spotify.track}`, `{spotify.artist}`, `{spotify.album}` in any tile label to render live-updating playback text.
- **Album cover as tile background** on playback tiles.
- Premium account required for playback ops (Spotify API restriction) — the config panel makes this visible and hides the ops from free-tier users' action picker.

## Per-app audio (new)

- Slider provider `app-audio` — one slider per running app that has an audio session. Drag to set volume, tap to mute the app.
- Actions: `toggle-mute`, `mute`, `unmute`, `set-volume` per app name.
- Powered by Windows Core Audio via PowerShell + inline C#. Only polls the session list while a layout tile actually needs live values.

## OBS depth

- **Scene preview thumbnails**: any `set-scene` tile shows a live thumbnail of that scene as the tile background. Server refreshes only for scenes referenced by the layout.
- **Media source controls**: play / pause / restart / stop / next / previous on any media (ffmpeg / VLC) input.
- **Browser source refresh**: one-tap refresh for any browser source in your scene collection.
- **Dynamic OBS labels**: `{obs.rec}`, `{obs.stream}`, `{obs.scene}`, `{obs.recTime}`, `{obs.streamTime}` — REC / STREAM timers tick locally on the phone between broadcasts.

## Action picker overhaul

- Search-first Stream-Deck-style picker: type "record" and every relevant op across every integration surfaces.
- Curated whole-tile preset library (label + icon + action set), separate from the flat catalog.
- Groups collapsed when the query's empty, revealed by typing.

## Discord finale

- **Kick-user** op.
- **Speaking indicators** on voice-panel tiles.
- **Bot-token move members** — with a bot token, "move to my VC" and "move to any VC" work across the whole server, not just your currently-connected channel.
- **Voice-channel panel tile**: live roster of your current VC with per-user volume + mute.

## Layout & templates

- ActionEditor split into per-integration body files (touching one integration doesn't force a re-review of every other).
- **Icon-pack support**: drop an SVG folder into `%APPDATA%/digi-deck/icon-packs/<pack>/` and Digi Deck picks it up in the icon picker.

## Ops

- Nightly traffic snapshot workflow commits `/traffic/{clones,views}` JSON to `metrics/` every day at 03:12 UTC.
- Release zip pipeline — the release asset is now built by CI on tag push (previously the update path fell back to `main.zip`).
